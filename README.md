# Flyvio Flight Booking

A responsive flight booking homepage created with semantic HTML5 and CSS3.

## Project structure

```text
flight-booking/
|-- index.html
|-- css/
|   `-- style.css
`-- images/
    |-- logo.png
    |-- campaign1.jpg
    |-- campaign2.jpg
    `-- campaign3.jpg
```

Open `index.html` in a browser to view the project. No installation or build step is required.

## Technologies

- HTML5
- CSS3
- Responsive media queries

This project intentionally contains no JavaScript, frameworks or backend code.
